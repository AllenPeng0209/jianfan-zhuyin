# 簡繁注音隱私政策

更新時間：2026-11-15T05:15:00+08:00

簡繁注音的注音解析、簡繁轉換、候選、個人詞庫、選字記憶與聯想排序都在本機完成。程式不設帳戶、廣告或分析服務，不會自動上傳輸入內容、詞庫或選字記憶。

啟用學習時，程式會保存選用的詞語、讀音、有限的短語上下文、選用次數與時間，供下次排序及還原使用。程式不保存逐鍵日誌或完整對話。你可以停用學習，或從管理介面清除選字與聯想記憶；個人詞庫可另外編輯、刪除及匯出。

iOS 鍵盤不要求「完整取用」。主程式管理共用詞庫及輸入偏好；鍵盤讀取這些資料，將學習紀錄保存在鍵盤自己的本機空間。主程式發出的清除指令會在下次開啟鍵盤時套用。

匯出的詞庫是你主動建立的檔案。只有在你自行選擇分享、同步或上傳時，該檔案才會離開本機；請依所使用服務的規則管理這些副本。

系統備份可能包含本機程式資料，其處理由 macOS、Windows 或 iOS 的備份設定決定。本政策涵蓋簡繁注音程式；你在其他應用程式中送出的文字，仍由該應用及其服務依自身政策處理。
