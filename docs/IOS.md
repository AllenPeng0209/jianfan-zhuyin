# iOS 版本

iOS 原生版本包含一個標準大千注音鍵盤擴充套件，以及詞庫管理與偏好設定主程式。支援簡繁輸出、候選、選字記憶、個人詞庫與聯想排序，最低系統版本為 iOS 16。

目前已通過實機架構編譯、模擬器核心測試、主程式與鍵盤共用視圖的操作測試，以及已建置內容的權限與詞庫檢查。App Store 公開下載仍需完成正式簽署、真機驗收及 Apple 審查。

## 使用方式

安裝後，在「設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤」加入簡繁注音，並以地球鍵切換。鍵盤不要求完整取用。

注音先顯示在鍵盤內的組字列。按聲調或「一聲」完成音節；點候選可更換選字，「聯想」提供接續詞。按「確認」或在音節完成後按空白鍵，才將組字送進目前應用。

主程式管理個人詞庫，可新增、修改讀音、刪除及匯入匯出 JSON。鍵盤讀取共用詞庫，選字及聯想記憶則保存在鍵盤自己的本機空間。主程式的清除指令會在下次開啟鍵盤時套用。

iOS 在密碼、部分電話欄位及不允許第三方鍵盤的應用中會使用系統鍵盤。硬體鍵盤輸入由系統處理。

## 建置與測試

```bash
bash scripts/test-ios.sh
python3 scripts/audit-ios-build.py build/iOSDerived/Build/Products/Debug-iphonesimulator/Jianfan.app --signed
```

腳本使用鎖定版本的 XcodeGen 產生 Xcode 專案，並選擇目前 SDK 相容的 iPhone 模擬器。模擬器建置使用本機 ad hoc 簽署，讓 App Group 權限可供驗證。

`JianfanSystemIntegration` 為另外的系統鍵盤驗證 scheme，會經由 iOS 設定加入鍵盤並在文字欄位測試。執行前請在模擬器的鍵盤設定中取消連接硬體鍵盤，讓軟體鍵盤與切換控制顯示出來。這項驗證與主程式內的鍵盤體驗測試分開記錄。

實機與 App Store 建置需使用已加入 Apple Developer Program 的團隊，並讓主程式與鍵盤的 App Group 一致。簽署資訊與私鑰不放入原始碼或公開安裝包。
